# Internlytic – Skills Assessment Platform

An online quiz and skills assessment platform built with **React and Vite**. Students can take quizzes, view results, and track their progress. Admins can manage quiz questions and categories.

## Features
- Student dashboard
- HTML, CSS, JavaScript & React quizzes
- Instant quiz results and scoring
- Quiz history and progress tracking
- Admin login dashboard
- Add, edit and delete questions
- Manage quiz categories
- Responsive design
- Local Storage for saving data

## Technologies
- React 18
- Vite 5
- JavaScript
- HTML5 & CSS3
- React Router
- Browser Local Storage

## Installation & Setup

**1. Clone the repository**
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Open the project folder**
```bash
cd internlytic-skills-assessment-platform
```

**3. Install dependencies**
```bash
npm install
```

**4. Start the development server**
```bash
npm run dev
```

**5. Open in your browser**

Visit: `http://localhost:5173`

## Other Commands

```bash
npm test       # Run tests
npm run build  # Build for production
npm run preview # Preview production build
```

## Admin Setup

1. Visit `/admin/login`.
2. Create your demo admin account on the first visit.
3. Log in to manage questions and categories.

## Data Storage

This project uses browser Local Storage. Data is saved locally on the user's device and is not synchronized between devices.

**Note:** Admin authentication is for demonstration purposes only, not production security.
